# Повторная индексация образцов расписаний за 2025 год

Дата анализа: 15 июля 2026 года.

Проиндексированы все 65 файлов DOCX из папки `Образцы расписаний 2025`. Для
контрольного сопоставления доступны 168 файлов учебных программ и планов. Анализ
выполнен по XML таблиц DOCX и дополнен ручным просмотром характерных расписаний.

## Проверенные закономерности

- Обнаружено 1030 строк с нумерованными учебными темами в 275 учебных днях.
- В 195 из 275 дней (71%) встречаются темы минимум из двух крупных разделов или
  учебных планов. В 88 днях (32%) одновременно представлены минимум три раздела.
- Поэтому несколько УТП необходимо чередовать уже с первых дней. Полное
  последовательное исчерпание одного плана перед началом следующего не отражает
  практику составителя.
- Найдены 174 сопоставимые темы, где присутствуют лекция и последующий иной вид
  занятия. В 173 случаях лекция расположена раньше. Единственное формальное
  исключение требует ручной трактовки исходного документа и не меняет общего
  правила.
- В расписаниях с группами общая лекция может занимать один временной слот сразу
  для двух групп, а последующие занятия разводятся по групповым колонкам.
- Итоговая аттестация формируется цельным блоком. Для продукта действует явно
  установленное пользователем правило: зачёт, экзамен и собеседование — ровно
  6 учебных часов, то есть три последовательных двухчасовых слота одного дня.

## Характерные примеры

В расписании переподготовки за период с 25 августа 2025 года уже в первый день
сочетаются лекции по идеологии, служебной деятельности, делопроизводству и
физической подготовке. В последующие дни темы этих направлений продолжают
чередоваться.

В образце `С группами.docx` лекция по теме предшествует практическому занятию,
после чего группы могут проходить разные занятия в одном временном интервале.
Итоговые виды контроля представлены непрерывными блоками.

## Следствие для алгоритма

Автопланировщик использует циклический выбор между источниками УТП. Для каждого
источника и каждой группы ведётся отдельный остаток часов. Нелектционный вид темы
становится доступен только после исчерпания лекционных часов этой же темы. Блок
аттестации становится доступен только после исчерпания всех неаттестационных
занятий своего УТП и при наличии трёх последовательных слотов до конца дня.

Источник УТП должен сохраняться при импорте каждой темы. Сопоставлять планы только
по названию дисциплины недостаточно: в разных документах могут встречаться
одинаковые номера и формулировки.

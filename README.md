# Конструктор расписаний (desktop)

Десктопное приложение (Electron + Vue 3) для составления расписаний учебных
занятий. Работает **полностью офлайн**: данные хранятся в локальной базе
(SQLite через sql.js) в каталоге пользовательских данных приложения.

## Возможности

- Импорт учебно-тематического плана (УТП) из `.docx` (распознавание таблицы,
  разделов, формы аттестации).
- Очередь тем и полу-/автоматическое распределение по учебным периодам.
- Конструктор расписания: drag-and-drop, закрепление занятий, массовый сдвиг,
  перемещение выделенных, undo/redo.
- Контроль накладок (Anti-Overlap): преподаватель/аудитория не могут быть заняты
  дважды в пересекающийся интервал; сквозная проверка по всем периодам.
- Временные изменения расписания (замена/отмена занятия на диапазон дат) с
  предпросмотром на конкретную дату.
- Справочники: преподаватели, аудитории, временные слоты, именованные сетки.
- Заметки, журнал изменений, архив версий и создание программы из шаблона со
  сдвигом дат.
- Экспорт расписания в `.docx` по шаблону Word.

## Архитектура

- `electron/main.js` — главный процесс: окно, каталоги данных/шаблонов, IPC.
- `electron/preload.cjs` — безопасный мост `window.api` (contextIsolation).
- `electron/backend/` — бизнес-логика (портирована из общего ядра):
  - `dispatcher.js` — единый диспетчер каналов (`dispatch(channel, payload)`);
  - `db/` — схема и адаптер sql.js (API совместим с better-sqlite3);
  - `ipc/` — обработчики каналов (programs, topics, periods, schedule, …);
  - `services/` — импорт/экспорт `.docx`, движок контроля накладок;
  - `templates/` — шаблоны Word для экспорта.
- `src/` — интерфейс на Vue 3 (Vue Router, Tailwind). Общается с ядром только
  через `src/api.js` → `window.api` (IPC).

Интерфейс обращается к ядру по именам каналов; тот же слой в web-версии работал
через HTTP-диспетчер — в desktop он заменён на Electron IPC без изменения логики.

## Разработка

```bash
npm install
npm run dev        # Vite dev-сервер + Electron с горячей перезагрузкой
```

## Сборка

```bash
npm run build      # сборка интерфейса в dist/
npm run start      # запуск Electron на собранном интерфейсе
npm run dist       # установщик под текущую ОС (electron-builder)
npm run dist:win   # / dist:mac / dist:linux
```

### Требования к среде сборки

Приложение использует **sql.js** (SQLite, скомпилированный в WebAssembly), поэтому
нативная пересборка под Node/Electron **не требуется** — установка проходит на
любой машине с Node.js LTS (20/22) без Python и C++ компилятора.

# Расписание — конструктор учебных занятий

Десктопное приложение (Electron) для автоматизации составления расписания учебных
занятий на основе учебно-тематического плана (УТП). Работает полностью **офлайн**,
данные хранятся локально в SQLite.

## Возможности

- **Импорт УТП** из файла `.docx` (с предпросмотром тем перед сохранением).
- **Очередь тем (FIFO)** — темы распределяются строго по порядку следования.
- **Учебные периоды** с настраиваемой сеткой занятий и **полуавтоматическим
  заполнением** оставшимися темами из очереди (темы, распределённые частично,
  идут первыми).
- **Конструктор расписания** с drag-and-drop и **контролем накладок в реальном
  времени** (Anti-Overlap Engine): один преподаватель или аудитория не могут
  стоять на двух пересекающихся по времени занятиях. Пересечение допускается
  только для разных групп.
- **Сквозная проверка** накладок по всем периодам программы (опционально).
- **Несколько групп** в рамках периода.
- **Архив версий**: сохранение снимков расписания, поиск, создание новой
  программы из версии-шаблона со сдвигом дат.
- **Экспорт в `.docx`** в формате, приближённом к образцу.

## Стек

Electron · Vue 3 (Composition API) · Vite · better-sqlite3 · TailwindCSS ·
vue-draggable-next · date-fns

## Требования

- **Node.js 20 LTS или 22 LTS** (рекомендуется). Для этих версий у
  `better-sqlite3` есть готовые бинарные сборки, и `npm install` проходит без
  компиляции.
- На более новых версиях Node (например, 24), где готовых бинарников ещё нет,
  для сборки нативного модуля потребуются инструменты сборки:
  - **Windows**: Visual Studio Build Tools (C++) + Python 3.
  - **macOS**: Xcode Command Line Tools (`xcode-select --install`).
  - **Linux**: `build-essential` (gcc/g++/make) + Python 3.

## Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Запустить в режиме разработки (Vite + Electron)
npm run dev
```

При первом запуске база данных создаётся автоматически и заполняется
справочниками (преподаватели, аудитории, временные слоты) из
`resources/seed-data.json`.

## Сборка дистрибутива

```bash
npm run dist          # для текущей ОС
npm run dist:win      # Windows (.exe)
npm run dist:mac      # macOS (.dmg)
npm run dist:linux    # Linux (AppImage)
```

Готовые установщики появятся в каталоге `release/`.

> Если после смены версии Node возникает ошибка загрузки `better-sqlite3`,
> пересоберите нативный модуль под Electron командой:
>
> ```bash
> npm run rebuild
> ```

```

├── resources/seed-data.json # Стартовые справочники
└── electron-builder.json5   # Конфигурация сборки
```

## Хранение данных

База SQLite располагается в пользовательском каталоге приложения
(`app.getPath("userData")/schedule.db`). При удалении приложения данные
остаются; чтобы начать с чистого листа, удалите этот файл.

## Замечания по реализации

- **Экспорт `.docx`** реализован программно через библиотеку `docx` (а не через
  шаблонизатор `docxtemplater`). Структура таблицы, шапка и блок подписей
  соответствуют образцу `Шаблон_расписания_с_УТП`. При необходимости точного
  посимвольного совпадения с конкретным шаблоном экспорт можно перевести на
  `docxtemplater` с готовым `.docx`-шаблоном.
- **Импорт `.docx`** использует `mammoth` (конвертация в HTML) +
  `node-html-parser` (разбор таблицы тем). Распознаются строки с номером темы,
  названием и количеством часов.
- **Часы на слот**: при автозаполнении один слот сетки расходует 2 академических
  часа темы (значение `HOURS_PER_SLOT`). Сначала расходуются лекционные часы,
  затем практические.

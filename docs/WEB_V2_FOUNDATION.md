# Веб-демонстрация и коммерческая десктопная версия

## Продуктовая модель

Schedule Automator состоит из двух разных продуктов с общим проверенным ядром:

1. **Веб-демонстрация.** Потенциальный клиент получает логин и временный пароль, ограниченное время пользуется всеми основными возможностями и знакомится с результатом.
2. **Полноценное десктопное приложение.** После покупки оно устанавливается в учреждении, работает автономно и не имеет ограничений по функциям или сроку использования приобретённой версии.

Веб-приложение не является платным SaaS-сервисом. В нём не нужны подписка, помесячная оплата, оплаченный период или продление доступа. Его задача — доказать ценность продукта и привести клиента к покупке десктопной версии.

## Путь клиента

1. Клиент видит рекламу или презентацию и оставляет заявку на демонстрацию.
2. Администратор создаёт отдельное демонстрационное пространство и выдаёт логин с временным паролем.
3. Пользователь входит, меняет временный пароль и видит дату окончания демонстрации.
4. Он может импортировать УТП, составить расписание, проверить накладки и сформировать DOCX.
5. По окончании срока вход блокируется. Данные хранятся до указанной даты удаления, чтобы демонстрацию можно было кратковременно восстановить.
6. Заинтересованный клиент приобретает десктопную версию и получает установку, первоначальную настройку и инструктаж.

## Веб-демонстрация

```text
Браузер
  -> вход / выход
  -> проверка срока демонстрации
  -> изолированное пространство учреждения
  -> API проверенного ядра расписаний
  -> PostgreSQL
```

Организация в веб-базе — только граница изоляции демонстрационных данных. Пользователь одного учреждения не может видеть данные другого. Срок демонстрации вычисляет сервер, а не браузер.

Серверная схема:

- `organizations` — отдельное демонстрационное пространство учреждения;
- `users` — выданные учётные записи;
- `organization_members` — принадлежность пользователя и его роль;
- `demo_access` — начало, окончание демонстрации и дата удаления данных;
- `sessions` — отзываемые серверные сессии;
- `audit_events` — входы, выходы и значимые действия.

В базе хранится `scrypt`-хеш пароля с отдельной случайной солью и только хеш токена сессии.

## Десктопная версия после покупки

- Работает без постоянного подключения к интернету.
- Не требует входа в демонстрационный веб-сервис.
- Не содержит пробного срока, платных функций или искусственных ограничений.
- Хранит рабочую базу в учреждении и поддерживает локальные резервные копии.
- Сохраняет проверенные автозаполнение, накладки, импорт УТП и DOCX.
- Может содержать сведения о владельце лицензии, но они не ограничивают работу законно приобретённой версии.

Рекомендуемая коммерческая поставка:

- бессрочное право использования приобретённой версии для одного учреждения;
- отдельно оплачиваемые установка, перенос данных и обучение;
- по желанию клиента — договор на обновления и техническую поддержку;
- новые крупные версии можно продавать отдельно, не отключая уже приобретённую.

## Порядок реализации

1. **Настольная база — выполнено.** Версия 1.0.5 проверена и закреплена тегом `desktop-v1.0.5`.
2. **Основа демонстрационного доступа — выполнено.** Организации, пользователи, роли, сессии, срок демонстрации и аудит.
3. Реализовать вход, выход, текущего пользователя и создание демонстрационной учётной записи администратором.
4. Перенести данные расписаний веб-демо в PostgreSQL с обязательной изоляцией по `organization_id`.
5. Добавить страницы входа, смены временного пароля, срока демонстрации и предложения купить десктопную версию.
6. Создать автоматическое удаление демонстрационных данных после срока хранения.
7. Подготовить коммерческий установщик десктопной версии, резервное копирование, инструкцию и пакет поставки.
8. Развернуть веб-демо по HTTPS и подготовить посадочную страницу для рекламы.

## Критерии готовности

- Веб-пользователь не может прочитать или изменить данные чужого демонстрационного пространства.
- Временный доступ прекращается по серверному времени, а выход немедленно отзывает сессию.
- Веб-демо показывает полный основной сценарий без скрытой оплаты внутри приложения.
- После покупки десктоп работает автономно и без функциональных или временных ограничений.
- Реальная база открывается в поставляемой десктопной версии без потерь.
- Автозаполнение, накладки, импорт УТП и DOCX совпадают с `desktop-v1.0.5`.

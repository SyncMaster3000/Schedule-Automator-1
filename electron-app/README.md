# Настольная версия для Windows

## Почему используется Electron

Рабочее приложение уже состоит из Vue 3, Express и Node-совместимой базы
`sql.js`. Electron запускает этот стек без переноса API на другой язык и без
нативных модулей. Tauri потребовал бы отдельного Node-sidecar или переписывания
сервера, поэтому для финальной Windows-версии он создаёт больше точек отказа.

В desktop-сборке Express и Electron работают в одном процессе приложения.
Сервер выбирает свободный порт, слушает только `127.0.0.1` и полностью готовит
БД до показа окна. Терминал, PowerShell и отдельный ручной запуск сервера не
нужны.

## Установка

1. Откройте файл
   `electron-app\release\Schedule-Automator-1.0.2-Offline-Setup.exe`.
2. Дождитесь автоматической распаковки и первого запуска программы.
3. При первом запуске выберите папку для базы. Можно оставить стандартное
   место или создать, например, `D:\ScheduleAutomatorData`.
4. В дальнейшем запускайте программу ярлыком **«Конструктор расписаний»** на
   рабочем столе или в меню «Пуск».

Программа устанавливается только для текущего пользователя в
`%LOCALAPPDATA%\Programs\ScheduleAutomator`, поэтому права администратора и
доступ к интернету не требуются.

При первом запуске окно разворачивается на рабочий экран. Это обычное окно
Windows с рамкой и стандартными кнопками; его можно восстановить, свернуть и
свободно изменить по размеру. Последний оконный режим сохраняется.

Сборка пока не подписана коммерческим сертификатом. Поэтому Windows SmartScreen
может показать предупреждение издателя; для внутренней установки нужно выбрать
«Подробнее» → «Выполнить в любом случае».

## Обновление

1. Закройте приложение.
2. Запустите установщик новой версии.
3. Дождитесь автоматической замены файлов и запуска приложения.

База, настройки и документы не находятся в каталоге установки и не
перезаписываются обновлением. Выбранная папка базы также сохраняется.

Версия 1.0.2 обязательна для установки на другом компьютере: в ней удалена
зависимость desktop-логирования от абсолютного пути компьютера сборки. Ошибки
`Cannot find module ... thread-stream-worker.mjs` и повторяющиеся окна
`The worker has exited` в этой версии не должны появляться.

Для удаления приложения закройте его, удалите каталог
`%LOCALAPPDATA%\Programs\ScheduleAutomator` и созданные ярлыки. Пользовательские
настройки останутся в `%LOCALAPPDATA%\ScheduleAutomator`, а база — в выбранной
папке. Их можно сохранить для повторной установки или удалить отдельно.

## Где хранятся данные

- база: `<выбранная папка>\schedule.db`;
- стандартное место базы:
  `%LOCALAPPDATA%\ScheduleAutomator\data\schedule.db`;
- сохранённый путь базы:
  `%LOCALAPPDATA%\ScheduleAutomator\settings\storage.json`;
- последняя папка экспорта:
  `%LOCALAPPDATA%\ScheduleAutomator\export-settings.json`;
- положение окна:
  `%LOCALAPPDATA%\ScheduleAutomator\settings\window-state.json`;
- документы Word: в папке, которую выбрал пользователь при экспорте.

Для резервной копии закройте приложение и скопируйте файл `schedule.db`.

Если после обновления приложение впервые предлагает выбрать место, а в
стандартной папке уже есть база, она безопасно копируется в выбранную папку.
Исходный файл остаётся на старом месте как резервная копия и автоматически не
удаляется. Если выбранный диск отключён или недоступен для записи, приложение
не создаёт незаметно пустую базу, а предлагает выбрать доступную папку.
После проверки расписаний в новой папке старую резервную копию
`%LOCALAPPDATA%\ScheduleAutomator\data` можно удалить вручную при закрытом
приложении.

## Сборка установщика

Из корня репозитория:

```text
pnpm install
pnpm --dir electron-app install
pnpm desktop:dist:offline
```

Готовый установщик:

```text
electron-app\release\Schedule-Automator-1.0.2-Offline-Setup.exe
```

Команда создаёт распакованную Electron-сборку и упаковывает её штатным
Windows IExpress в один автономный EXE. Альтернативную NSIS-сборку можно
подготовить командой `pnpm desktop:dist:win`, когда локально доступен комплект
NSIS для `electron-builder`.

Распакованная проверочная сборка без мастера установки:

```text
pnpm desktop:pack:win
```

Её исполняемый файл находится в
`electron-app\release\win-unpacked\ScheduleAutomator.exe`.

Папки `runtime` и `release` генерируются автоматически и не добавляются в Git.
